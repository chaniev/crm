# TASK-226. Логины администраторов локального тестового набора

## Status

done

## Requirements

## Решение владельца

22.11.2026 владелец попросил убрать префикс `seed` из логина администратора при создании локальных тестовых данных. Для пяти администраторов полного набора это даёт логины от `admin01` до `admin05`.

## Проверка

На исходной версии интеграционный тест получил логины с префиксом. После исправления он подтвердил логины от `admin01` до `admin05` в PostgreSQL при первом и повторном заполнении. Все 880 backend-тестов прошли.
