# Приёмка TASK-177 · 21.11.2026

В коммите `ace8c018` декоративная обёртка флажка пропускает указатель, а нативный input и связанная подпись обрабатывают выбор дня. На исходной версии два теста упали при выборе «Пн» в точке (28, 32) CSS px от верхнего левого угла. Пропуск воспроизведён мышью и касанием в Chromium.

После исправления на каждом из семи дней нажатие в (28, 32) выбирает день и показывает одно поле времени, нажатие в (42, 23) снимает выбор. Соседние дни остаются снятыми. Размеры — 63,92–66,97 × 46 CSS px. В центральном квадрате 44×44 каждая из 1936 проверенных точек принадлежит соответствующему input или его подписи. Проверены мышь, профиль Pixel 7 с включённым сенсорным вводом и два профиля WebKit. [Измерения по каждому дню](measurements.json).

На production-сборке клавиша Space переключает день и восстанавливает время. При фокусе видна обводка. Во время отправки видны выбранные дни, касание не меняет их состояние. Геометрия блока до и после совпала в трёх профилях. [До](before-focus.png) · [После](after-focus.png) · [Во время отправки](after-disabled.png).

[Проверка кандидата](harness.json) и [проверка объединённого кода](batch-harness.json) прошли. На `db3f22e6` выполнены 820 модульных тестов и 52 сценария групп, включая длинную ошибку времени, ограничение доступа, малую высоту и редактирование серии. В двух проектах WebKit тест, специально объявленный для сенсорного Chromium, пропущен по условию. Их собственный тест касаний прошёл. Проверки выполнены с браузерными фикстурами API и мобильной эмуляцией.
