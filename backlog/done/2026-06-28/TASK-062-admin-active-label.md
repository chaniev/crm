## Goal
При оформлении администратора интерфейс показывает корректный текст про администратора, а не ошибочную подпись про тренера.

## Context
В inbox зафиксирована заметка: `Оформляя админа снизу написано не админ активен а тренер`.

Похоже на локальную UI-регрессию в форме создания или редактирования администратора: нижняя подпись/переключатель активности переиспользует текст из тренерского сценария.

## User role
главный тренер / администратор

## Problem
В администраторском сценарии пользователю показывается текст про тренера. Это сбивает с толку и создает ощущение, что создается не тот тип сотрудника, даже если backend-роль выставляется правильно.

## Scope
- Найти форму создания/редактирования администратора в настройках.
- Найти подпись, hint, checkbox label или summary-текст, где отображается `тренер активен` в администраторском сценарии.
- Заменить текст на корректный вариант для администратора.
- Проверить, не переиспользуется ли тот же компонент в форме тренера; для тренера текст должен остаться корректным.
- Добавить или обновить легкий regression test, если для формы администратора уже есть frontend coverage.

## Out of scope
- Изменение ролей, permissions или backend contract создания администратора.
- Перенос управления администраторами между разделами.
- Добавление новых полей администратора.
- Редизайн формы.

## Constraints
- Не менять backend-owned role semantics.
- Не возвращать поле выбора роли в create-flow администратора.
- Исправление должно быть контекстным: trainer flow продолжает показывать тренерский текст, administrator flow - администраторский.
- Если текст хранится в общем компоненте, нужно передать явный контекст, а не хардкодить новый общий текст, который сломает форму тренера.

## Acceptance criteria
- [ ] В форме оформления администратора нижний текст говорит про администратора, а не про тренера.
- [ ] В форме тренера текст по-прежнему говорит про тренера.
- [ ] Создание администратора по-прежнему использует существующий `/settings/administrators` flow и не меняет роль вручную.
- [ ] Нет новых русско-английских или технических подписей в пользовательском UI.

## Test checklist
- [ ] Запустить `cd frontend && npm run lint`.
- [ ] Запустить `cd frontend && npm run build`.
- [ ] Добавить или обновить frontend test/e2e на отображение текста в форме администратора, если рядом уже есть покрытие.
- [ ] Вручную открыть форму добавления администратора и проверить нижний текст.
- [ ] Вручную открыть форму добавления тренера и проверить, что текст не сломан.
