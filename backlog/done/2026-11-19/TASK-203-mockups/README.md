## Бриф и границы

Администратор создаёт группу и начальное расписание из реестра групп.
Основание — принятое [REQ-GRP-008](../../../../docs/requirements/02-группы.md)
и [план](../TASK-203-group-create-single-action.plan.md).
Сохраняются порядок полей, Mantine, Onest и тема. В редакции A.2 по решению
владельца удалена нижняя сводка, повторявшая выбранные значения.
Визуальный замысел: одно очевидное действие создания и понятное восстановление
в той же форме. Новый визуальный стиль и перестройка экрана не предлагаются.

Путь: заполнение → «Создать группу» → ожидание → подтверждённый успех и список.
При исправимой ошибке пользователь остаётся в заполненной форме.
При неизвестном результате доступна проверка списка без повторной отправки.
Предупреждение об уходе применяется к действиям приложения; кнопки браузера
не блокируются, приложение не сохраняет и не восстанавливает потерянный ввод.

## Контракт варианта A

| Состояние | Представление и действия |
|---|---|
| Готова | Одна кнопка «Создать группу», текущий порядок полей без нижней дублирующей сводки; необязательные окончание расписания и тренеры подписаны явно |
| Ожидание | «Создаём…», поля и повторный submit недоступны; действия ухода доступны |
| Ошибка дней | Сообщение у дней недели; фокус на первом дне, сохранённые зал и длительность не помечаются ошибочными |
| Отказ в доступе | Понятная причина над формой, сохранённый ввод, фокус на сообщении |
| Результат неизвестен | Постоянное сообщение «Результат создания не подтверждён»; основная кнопка «Проверить список групп»; повторное создание из состояния недоступно |
| Уход через приложение | Диалог «Выйти без сохранения?»; «Остаться» получает начальный фокус; Escape закрывает диалог и возвращает фокус инициатору |
| Уход во время создания | Диалог объясняет потерю ввода и возможное завершение операции после ухода; подтверждённый уход разрешён |
| Переход к проверке списка из неизвестного результата | Тот же диалог потери ввода, дополненный напоминанием проверить группу в списке |
| Успех | Именное подтверждение, возврат в список, предупреждение снято |
| Сбой справочников | Сообщение и «Повторить»; во время повтора показана загрузка |
| Нет вариантов / нет права | Понятная причина недоступности; отправка формы отсутствует |

В узком окне — одна колонка и закреплённое основное действие над навигацией;
на desktop сохраняются две колонки. Диалог выше навигации и панели действий,
кнопки диалога на узком экране расположены вертикально. Названия и сообщения
переносятся; выбранные длинные значения в полях можно просматривать в самих
полях/раскрытых списках. Повторного представления выбранных значений под формой нет.

## Выполненная проверка

Экспертный проход в браузере Codex, без реального сервера и пользовательского исследования.

- Успешное создание одним нажатием с ожиданием и именным результатом — пройдено.
- Ошибка пустых дней → фокус на дне → исправление → успешное создание — пройдено.
- Подтверждённая ошибка доступа сохраняет название и возможность новой попытки — пройдено.
- Неизвестный результат блокирует повторное создание и показывает проверку списка — пройдено.
- Диалог ухода: начальный фокус, Escape, возврат фокуса и сохранение ввода — пройдено.
- Подтверждённый уход во время ожидания и последующее появление демонстрационной
  группы в списке — пройдено; это симуляция результата, не проверка транзакции.
- Автоматические начальные значения пустой формы не вызывают предупреждение — пройдено.
- Browser Back/Forward из изменённой формы не открывают диалог; после возврата
  введённое название пустое — пройдено в маршрутах прототипа.
- Нет доступных филиалов, ограничение роли «Тренер», повтор загрузки — пройдено.
- Длинные данные на 360×780, 390×844, 420×912, 440×956, 768×1024,
  912×420, 956×440, 1440×1200: горизонтальной прокрутки нет.
  На 360–768 основная кнопка высотой 44 px находится над нижней навигацией.
  При 912×420 действия диалога видимы в пределах окна.
  [Измерения](viewport-checks.json); снимки `long-<ширина>.jpg` находятся рядом.
- TypeScript и отдельная сборка прототипа — PASS. Сборщик сообщает о размере
  демонстрационного JS-пакета более 500 kB; это не изменение производственной сборки.

При проверке исправлены фокус ошибки группы дней и слой диалога относительно
закреплённых элементов. Это изменения только временного прототипа.

## Ограничения и выбор

Серверные ответы, права, сохранение и список имитируются. Прототип не подтверждает
токены, атомарность, идемпотентность, серверную валидацию, импорт или рабочую навигацию.
Неблокирующие предупреждения не показаны в интерфейсе по принятому требованию;
серверная цепочка проверяется при реализации. Не проверены реальные Safari-панели,
экранная клавиатура, физический iPhone/Simulator, WebKit и экранный диктор.
Проверка размеров в браузере не заменяет эти проверки.

Компромисс: сохраняется текущий состав полей; дублирующая сводка удалена. Сокращено число
отправок пользователем (два нажатия → одно), но время работы не измерялось.

без сводки. Позднее в тот же день отдельно согласован технический контракт
