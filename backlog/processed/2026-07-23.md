по абонементам:
Не сохраняется отредактированный абонемент
Не дает сохранить второй абонемент
Функция продления абонемента тоже выдает ошибку
Если выставлять абонемент как неоплаченный, не дает внести изменения и отметить оплату
Если оформлять абонемент на срок, то срок по правилу можно выставить только при редактирования абонемента, а они на данный момент просто не редактируются

по клиентам:
Нет даты рождения в профиле 

по группам:
У администратора нет вообще функции отметить группу
Доступа к редактированию типов групп тоже нет
