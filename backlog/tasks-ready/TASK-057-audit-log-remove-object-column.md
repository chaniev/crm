# TASK-057: Убрать лишний заголовок и колонку Объект из журнала

## Status
ready

## Goal
Журнал действий выглядит чище: пользователь не видит лишний текст `Записи журнала` и техническую колонку `Объект`, где отображается сессия пользователя.

## Context
В inbox зафиксировано пожелание: в журнале удалить текст `Записи журнала` и убрать из отображения колонку `Объект`, где сейчас показывается сессия пользователя.

## User role
Администратор / главный тренер.

## Problem
Экран журнала содержит визуально лишний заголовок и техническую колонку, которые мешают быстрому просмотру событий и выводят пользователю низкоуровневые данные.

## Scope
- Убрать видимый текст `Записи журнала` на экране журнала.
- Убрать колонку `Объект` из отображаемой таблицы/грида журнала.
- Сохранить остальные полезные колонки журнала, фильтры, пагинацию и просмотр деталей.
- Обновить frontend-проверки журнала, если они завязаны на старый заголовок или колонку.

## Out of scope
- Изменение backend audit contract, audit persistence или audit semantics.
- Удаление данных об объекте из backend response.
- Изменение прав доступа к журналу.
- Переработка фильтров журнала вне необходимой адаптации к удаленной колонке.

## Constraints
- Backend остается source of truth для audit data, ролей и доступа.
- Не ломать журнал для администратора и главного тренера.
- Не скрывать технические данные в деталях события, если они нужны для диагностики и уже доступны по текущему UX.
- Не дублировать audit/domain rules во frontend.

## Acceptance criteria
- [ ] На экране журнала больше нет текста `Записи журнала`.
- [ ] В таблице/гриде журнала больше нет видимой колонки `Объект`.
- [ ] События журнала по-прежнему показывают дату/время, действие, описание, автора, источник и доступное действие просмотра деталей.
- [ ] Фильтры, пагинация и открытие деталей события работают как до изменения.
- [ ] Доступ к журналу для разрешенных ролей не изменился.

## Test checklist
- [ ] Вручную проверить экран журнала под администратором.
- [ ] Вручную проверить экран журнала под главным тренером.
- [ ] Обновить или добавить frontend unit/e2e проверку, что колонка `Объект` не отображается, а журнал продолжает рендериться.
- [ ] Запустить frontend lint + build.
