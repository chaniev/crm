# TASK-041: Переименовать кнопку включения признака профессионала

## Status
ready

## Goal
Кнопка включения признака клиента использует продуктовый термин "Профессионал", а не устаревшее слово "льгота".

## Context
В inbox есть заметка: `переименовать кнопку "включить льготу" на "Профессонал"`. В реализованной задаче `TASK-027` признак уже переименован в `профессионал`, но во frontend-коде и e2e-сценариях еще встречаются кнопки `Включить льготу` и `Отключить льготу`.

## User role
главный тренер

## Problem
Старое название кнопки создает терминологическое расхождение: остальные части CRM говорят о признаке профессионала, а action-кнопка продолжает говорить о льготе.

## Scope
- Найти frontend-кнопки включения и отключения признака профессионала.
- Переименовать `Включить льготу` в `Профессионал` или в согласованную action-формулировку с этим термином.
- Обновить связанную кнопку отключения, если рядом остается устаревшее слово `льгота`.
- Обновить e2e/unit tests и selectors, которые завязаны на старый текст кнопки.
- Проверить, что остальной текст про комментарий/основание остается понятным.

## Out of scope
- Изменение backend-модели признака профессионала.
- Изменение прав включения/отключения признака.
- Изменение финансовой, attendance или debtor-семантики `профессионала`.
- Переименование маршрутов или API-полей.

## Constraints
- Backend остается source of truth для признака профессионала, прав и финансовой семантики.
- Не возвращать старую терминологию `нулевой абонемент`.
- Учитывать существующие e2e-тесты вокруг professional client flow.

## Acceptance criteria
- [ ] Во frontend action-кнопке больше не используется текст `Включить льготу`.
- [ ] Текст отключения признака тоже согласован с термином `Профессионал`.
- [ ] Пользователь понимает, что действие включает или отключает признак профессионала.
- [ ] Обновлены тесты, которые искали старые тексты кнопок.
- [ ] Backend contract и business rules не изменены.

## Test checklist

- [ ] Запустить `cd frontend && npm run build`.

- [ ] Вручную проверить карточку клиента с правами главного тренера и без них.
