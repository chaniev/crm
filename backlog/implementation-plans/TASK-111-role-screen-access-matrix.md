# TASK-111 — текущая матрица доступности экранов для ролей

Актуальность: 2026-08-19.

Матрица описывает фактическую текущую реализацию. Источником истины остаются
backend permissions, access scope и данные пользовательской сессии. Этот файл
не создаёт отдельную модель разрешений и должен быть синхронизирован при
изменении backend-контрактов, маршрутов или состава экранов.

## Роли

| Роль в интерфейсе | Системное имя |
|---|---|
| Главный тренер | `HeadCoach` |
| Суперадминистратор | `SuperAdministrator` |
| Администратор | `Administrator` |
| Тренер | `Coach` |

## Правила чтения матрицы

- «Нет доступа» означает, что маршрут или область не должны быть доступны, а
  UI не должен отправлять относящиеся к ним API-запросы.
- «В своей области» означает ограничение, полученное из backend: филиал,
  выданные группы или назначенные тренеру группы.
- Наличие основного экрана не гарантирует наличие каждой операции внутри
  него. Кнопки создания, редактирования и отдельные вкладки зависят от
  permissions и дополнительных session-полей.
- Для автоматической регрессии TASK-111 роли должны задаваться через реальные
  session/backend fixtures. Копировать эту таблицу как новый набор permission
  booleans в frontend-тесты нельзя.
