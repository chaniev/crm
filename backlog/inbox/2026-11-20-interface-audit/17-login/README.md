О: логин + пароль + «Войти» = 3 логических действия. Успешно выполнено для двух тестовых учётных записей. Г: сохранить 3; автозаполнение может сократить ввод, но отдельно не проверялось.

## Находки и приоритет

- **LOG-01 · low · гипотеза:** «Добро пожаловать!» — нейтральное приветствие; его удаление почти не влияет на число действий. Приоритет ниже проблем рабочих экранов. Можно заменить на «Вход» для прямой постановки задачи.
- **LOG-02 · medium · подтверждено:** имя переключателя видимости пароля не локализовано. Общая причина с экраном смены пароля; один общий пункт доработки, не две независимые задачи.
- Экран уже содержит минимальный набор полей; добавлять подсказки о внутренних режимах, ролях и реализации не нужно.
