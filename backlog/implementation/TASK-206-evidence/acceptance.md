# Проверка филиала администратора · 21 ноября 2026

На исходной версии `bf14d61` три новых проверки HTTP вернули корректный ID филиала и пустое имя в списке и ответе создания. Отдельно по плану воспроизведено то же расхождение для GET деталей. Тесты использовали изолированные данные EF InMemory с двумя филиалами. После исправления прошли все 16 тестов AdministratorAttendanceGrantApiTests, включая смену филиала, архивное назначение и отказы доступа. Шесть новых проверок Vitest на исходной версии обнаружили потерю различия между отсутствующим полем и явным null.

## Отдельный проход по диалогу

Проверены Chromium, iPhone Air WebKit и iPhone 17 Pro Max WebKit. После успешного чтения Escape возвращает фокус на кнопку «Группы посещений» того же сотрудника. Enter снова открывает диалог. При HTTP 503 диалог сохраняет имя сотрудника и выводит «Группы не загрузились». После закрытия фокус также возвращается на вызвавшую кнопку. [Ошибка на узком экране](error.png).

Мобильная проверка выполнена в эмуляции Playwright. Панели Safari, экранная клавиатура, аппаратные безопасные отступы и VoiceOver на устройстве или в Simulator отдельно не проверялись.
