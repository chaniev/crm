# TASK-204: диагностика и приёмка

База: `0d0fd64fce4d5dacde1b9ea5763c15f28a1684a9`. Дата: 20.11.2026.
Данные синтетические; PostgreSQL `postgres:17-alpine`, отдельные Testcontainers.
Общий локальный стенд и его данные не изменялись.

## Причина и исправление

`NormalizePhoneSearch` удаляет форматирование, но сохраняет буквы. Для
HeadCoach/Administrator/SuperAdministrator запрос «Алексеев Алексей» после
проверки каждого слова дополнительно требовал совпадения склеенной строки
«АЛЕКСЕЕВАЛЕКСЕЙ» с одной частью имени или телефоном. Это давало ноль результатов.
Для одного слова дополнительное условие пропускалось. Исходное падение — red.txt.

Дополнительное условие применяется только к числовому телефону. Токенизация,
область доступа, формат API, данные и интерфейс сохранены.

## Реальный UI → HTTP → PostgreSQL

`client-full-name-search.spec.ts` запускает настоящий Kestrel и PostgreSQL
через существующий BranchSettingsAppFactory. Вход HeadCoach, status=Active,
page=1, pageSize=20. Последовательно отправляются query=Алексеев,
query=Алексеев Алексей, query=Алексеев Алексей Дмитриевич. Для каждого ответа
проверены totalCount=1 и fullName=Алексеев Алексей Дмитриевич, затем имя в DOM.
Раздельные поля в БД заданы в SeedAsync теста; запрос декодирован через
URL.searchParams. Attachments содержат роль, запрос, ответ и снимок DOM.
Тесты прошли в Chromium, iphone-air-webkit и iphone-17-pro-max-webkit.

Под Coach проверены доступный клиент назначенной группы, отсутствие телефона
в DOM и пустая выдача номера. PostgreSQL-тесты дополнительно проверяют
Administrator против тёзки чужого филиала, глобальные роли, счётчики,
пагинацию по одному клиенту, query/search/fullName, пробелы, регистр и phone=403.

## Отдельный проход аудита

После функционального прогона отдельно просмотрены chromium.png и
iphone-air-webkit.png; текст результата читаем, ФИО переносится в строке,
поиск и очистка видимы. Композиция соответствует существующему списку из
исходного аудита; рабочие компоненты и стили не изменялись.
Доступное имя поля проверено role= textbox; программный фокус и выход Tab
проверены браузером. Ошибка и повтор проверены с единственной подменой 500,
успешный повтор снова обращается к реальному backend. Очистка сохраняет
действующий статус; поздние ответы проверены отложенными Promise отдельно.
Новых доказанных дефектов изменённого поиска в этом проходе нет.

WebKit является эмуляцией. Физический iPhone, Safari browser chrome и экранная
клавиатура не проверялись; их проверка не заявляется.
