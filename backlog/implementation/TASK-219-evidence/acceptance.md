# Приёмка TASK-219. Полный состав занятия

На исходной версии три компонентные регрессии открыли занятие, но не нашли группу «Показывать клиентов». После исправления 53 теста экрана прошли, включая сохранение в процессе переключения и занятие с запретом записи.

На [телефоне](roster-390.png) и [компьютере](roster-1440.png) переключатель расположен между шапкой занятия и первой карточкой, как в согласованном сравнении. В режиме «Все» рядом с именем каждого клиента видна его сохранённая отметка. Использованы тестовые ответы API.

В отдельном проходе Chromium на 390 и 1440 px клавиша Tab привела к фильтру, стрелка вправо открыла полный состав. У выбранной подписи браузер показал сплошной контур 3 CSS px. Следующий Tab перевёл фокус к выбору отметки в карточке клиента. Стрелка влево внутри фильтра вернула список неотмеченных. Проверены также 912 × 420 и сенсорное переключение в двух профилях iPhone WebKit. Во всех проверенных размерах список поместился по ширине.

В Safari 26.4 на симуляторе iPhone Air при видимой области 420 × 746 CSS px активация DOM-элементов через WebDriver переключила список в обе стороны. При попытке сенсорного ввода через драйвер журнал страницы получил начало касания без события отпускания. Сенсорный путь на симуляторе и физическом устройстве остаётся непроверенным.
