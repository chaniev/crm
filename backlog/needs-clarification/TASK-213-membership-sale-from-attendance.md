# TASK-213: Оформление абонемента из списка занятия

## Goal
Администратор с правом продажи оформляет абонемент для выбранного спортсмена и возвращается в список того же занятия.

## Context
Из посещаемости уже открывается карточка клиента с возвратом к строке. Есть форма продажи с серверными правилами целевых групп и суммы. Применимы [REQ-SUB-002, REQ-SUB-003, REQ-SUB-006 и REQ-SUB-008](../../docs/requirements/03-абонементы-и-оплаты.md).

## Scope
Предложить у строки с истёкшим абонементом действие «Оформить абонемент». Открывать существующую форму с выбранными клиентом и группой занятия, учитывая допустимые варианты по серверному контракту.

## Acceptance criteria
- [ ] Сотрудник с правом продажи открывает форму из нужной строки. До подтверждения видны клиент, целевые группы и сумма.
- [ ] После продажи или выхода из формы открывается исходное занятие. Состояние строки соответствует сохранённому результату, несохранённые отметки не теряются молча.
- [ ] Без права продажи действие недоступно. Тренер с правом отметки может сохранить фактическое посещение независимо от оформления абонемента.
- [ ] Согласованное поведение отражено в реестре требований и [журнале изменений](../../docs/requirements/CHANGELOG.md).

## Test checklist
- [ ] Проверить спортсмена из нескольких групп, отмену формы, несохранённые отметки и повтор после сбоя ответа без второй продажи.

## AI safety
- Safe for autonomous implementation: no
- Risk level: medium
- Reason: Ошибочно выбранная группа меняет привязку продажи, повторное подтверждение может исказить финансовый учёт.
