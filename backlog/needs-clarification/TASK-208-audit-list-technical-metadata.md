# TASK-208: Убрать технические метаданные из рабочих строк журнала

## Status
needs-clarification

## Requirements
- REQ-AUD-002 — implements
- REQ-NFR-001 — constrains

## Goal
Журнал сканируется по времени, человеческому описанию и автору; технические данные доступны в деталях.

## Context
AUD-01: в строке рядом с описанием выводятся техническое действие, тип объекта, UUID и источник; на телефоне описание обрезается. REQ-AUD-002 уже требует убрать технические объект/действие из списка. Завершённые TASK-057/099 удаляли отдельные колонки; текущая находка относится к метаданным внутри строки.

## User role
Сотрудник с разрешённым доступом к журналу.

## Problem
Диагностические данные вытесняют полезное описание события.

## Scope
- Убрать тип объекта, идентификатор и дублирующий технический тип действия из основной строки, сохранив их в доступных деталях.
- Проверить необходимость постоянного источника Web в строке в рамках прототипа; источник в деталях сохраняется.
- Сохранить время, описание, отдельного автора, фильтры, пагинацию и открытие деталей.

## Out of scope
Изменение audit payload/хранения, перезапись исторических описаний, новые тексты неизвестных enum (TASK-185), редизайн деталей.

## Constraints
Не терять возможность диагностики события. Не переписывать сохранённые строки ради удаления повторного имени автора. Escape/возврат фокуса и доступность деталей сохраняются.

До изменения кода нужен готовый план по docs/HARNESS.md. Визуальные решения проходят применимые этапы docs/DESIGN_PROCESS.md и выбор на проверенном прототипе. Этот разбор не утверждает прототип и не разрешает реализацию. При реализации актуализировать затронутые REQ и docs/requirements/CHANGELOG.md.

## Acceptance criteria
- [ ] В рабочих строках mobile/desktop нет технического объекта, UUID и дублирующего кода действия; описание и автор читаемы.
- [ ] За одно открытие доступны полные технические данные события.
- [ ] Фильтры по типу действия, пагинация, клавиатура и возврат фокуса работают как прежде.

## Test checklist
- [ ] Проверить длинное описание и автора, разные типы/источники, пустую выдачу, пагинацию, открытие/закрытие деталей.
- [ ] Сравнить 390/768/1440 px; исходные payload и история не изменены.
