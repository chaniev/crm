# Обновление CRM — 20 ноября 2026

## Импорт клиентов из Excel

В настройках можно загрузить новых клиентов из XLSX. Доступные филиалы зависят
от прав сотрудника. Если в файле найдены ошибки, CRM показывает строки и причины;
часть файла отдельно не сохраняется. Если результат загрузки неизвестен,
операцию можно проверить в журнале по её номеру перед повторной отправкой.

Для пустого телефона подставляется `+79111111111`. Непустой телефон неверного
формата остаётся ошибкой, которую нужно исправить в файле.

## Создание групп

Группа создаётся одним нажатием. В форме доступны только подходящие филиалы
и залы; при ошибке введённые данные сохраняются. Переход внутри приложения
предупреждает об уходе из незавершённой формы. Если результат сохранения
неизвестен, форма предлагает проверить список групп, чтобы избежать дубля.

## Назначения тренеров и расписание

Последний день назначения тренера теперь входит в период. Можно назначить
тренера на один день; доступ к группе обновляется согласованно с назначением.

Бот показывает актуальные занятия так же, как веб-интерфейс: с переносами,
разовыми занятиями и заменами тренеров. Отменённые занятия остаются видимыми,
но без кнопки отметки посещаемости.
