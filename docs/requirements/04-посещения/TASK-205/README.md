HTML открывается в браузере из файла. Кнопка «Сценарии» в правом верхнем углу переключает примеры. Занятия и клиенты вымышлены, отметки хранятся в памяти вкладки до перезагрузки.

## Что оцениваем

Сотрудник открывает состав и перед первой отметкой сверяет группу, дату и интервал конкретного занятия. Если открыто другое занятие, одного нажатия достаточно для возврата к выбору. В исходном экране после перехода оставались общий заголовок и дата. Путь от выбора до отметки сохраняет два действия. [Исходный экран и наблюдения](../../../../backlog/processed/2026-11-20-interface-audit/21-attendance-lesson/README.md)

Название группы занимает первую строку шапки. Дата и время находятся рядом строкой ниже. Длинное название переносится полностью. На широком экране кнопка возврата находится справа, на телефоне переходит под время. Шапка прокручивается вместе с составом. Отдельная строка кнопки увеличивает высоту мобильной шапки и оставляет меньше места для второй карточки клиента.

## Как посмотреть

| Вход или состояние | Действие и наблюдаемый результат |
|---|---|
| Посещения сегодня | В «Сценариях» откройте «Посещения сегодня». Сравните утреннее и вечернее занятия «Самбо · Юниоры», затем две группы в 08:00. После возврата фокус снова у выбранного занятия. Рабочий список сохраняет позицию и умеет выбрать следующую строку при исчезновении исходной. |
| Расписание | Откройте разовое занятие или занятие, перенесённое с 17:00. В шапке перенесённого занятия стоит 18:30–19:30. «К расписанию» возвращает к выбранной дате и занятию. Вход показан на сокращённом фрагменте расписания. |
| Прямая ссылка | При открытии HTML виден состав утреннего занятия. Вариант возврата без исходного списка ведёт в «Занятия на сегодня». Можно скопировать адрес другого занятия и открыть в новой вкладке. |
| Ошибка и повтор | Пока загружается контекст, видны индикатор и возврат. При сбое доступна кнопка «Повторить». После повтора появляются данные того же занятия и состав, фокус переходит на название группы. |
| Ограничения | Для недоступного занятия видны сообщение и возврат. Для будущего занятия из расписания видны состав, причина ограничения и заблокированные отметки. |
| Отметка | Нажмите «Был» в демонстрационном составе. После подтверждения строка уходит из списка неотмеченных. У другого занятия той же группы этот клиент по-прежнему не отмечен. |

## Границы выбора

Владелец согласовал компоновку шапки, подписи возврата, переход к сегодняшним занятиям при прямом входе и показ состава после идентификации занятия. Дата «20 ноября 2026» иллюстрирует локальный вариант. Общий формат дат ведётся в TASK-175. Прикладные строки состава, три состояния и рабочий список сегодня взяты из CRM. Внешняя навигация прототипа включает два входа в рассматриваемый сценарий.

Для примеров используется точная пара идентификатора занятия и даты. В рабочей системе ответ состава содержит название группы и дату, но в нём отсутствует интервал занятия. Клиент расписания уже запрашивает занятие по идентификатору и дате. При подготовке плана подтверждены чтение деталей через действующий API расписания и независимая проверка доступа к составу. Прототип не задаёт новый API и не проверяет серверную запись или сохранённый снимок времени. ## Проверка 21.11.2026

- Выполнен экспертный проход в Playwright. На ширинах 360, 390, 768 и 1440 px, а также при 912 × 420 и 956 × 440 в Chromium проверены обычное и длинное названия. - На ширине 390 px проверены переход по Tab и возврат по Enter, фокус строки, смена даты в расписании, прямая ссылка, повтор после сбоя, доступ только для чтения и отметка в одном из двух занятий. На мобильных профилях WebKit 420 × 912 и 440 × 956 проверены те же сценарии с сенсорным возвратом. Видимая область уменьшена по профилю проекта.
- Проверены загрузка, отказ доступа и несовпадающая пара занятия и даты. Во всех трёх случаях действия отметки отсутствовали. Сборка и проверка типов прошли. Автономный HTML также открыт локально в Chromium с переходом к выбору занятий.
- Проверка выполнена с локальными ответами в памяти. Работа с реальным сервером, VoiceOver, Safari на физическом iPhone, системная клавиатура и безопасные отступы устройства остаются за границами этого прохода.
