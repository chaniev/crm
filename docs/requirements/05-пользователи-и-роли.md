# Требования: Пользователи и роли

Доменный код: `USR`.

> При миграции перенести сюда матрицу прав из `docs/MVP-ТЗ.md` целиком —
> она является базовой карточкой этого домена.

### REQ-USR-001. Роли пользователей

**Статус:** предложено

Роли: Главный тренер, Администратор, Тренер. Главный тренер имеет доступ ко
всему функционалу. Тренер отмечает посещения. Администратор управляет
абонементами, оплатой и сроками действия. Разграничение прав реализуется
бекендом (см. корневой `AGENTS.md`).

**Изменения:**

### REQ-USR-002. Первый вход и начальная учетная запись

**Статус:** предложено

При развертывании системы создается пользователь с ролью Главный тренер и
паролем 12345678. При первом входе в систему пользователь обязан сменить пароль.
