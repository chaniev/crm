### REQ-GRP-001. Карточка группы

**Статус:** реализовано

Группа имеет: название, тип группы (справочник настроек), филиал, зал
(внутри филиала), недельный график занятий, список клиентов, список
тренеров. Группа относится строго к одному филиалу и залу. Создание и
редактирование групп — Главный тренер, Супер-администратор, Администратор.

**Изменения:**

- 27.08.2026 — новая (источник: MVP-ТЗ, TASK-022, TASK-031).

### REQ-GRP-002. Клиенты и тренеры в группах

**Статус:** реализовано

Клиент может состоять в нескольких группах; группа содержит несколько
клиентов; у группы может быть несколько тренеров. Назначенный тренер
получает права отметки посещений в этой группе. Главный тренер может быть
назначен тренером любой активной группы. Архивация группы блокируется
действующими и будущими привязками абонементов к ней.

**Изменения:**

- 27.08.2026 — новая (источник: MVP-ТЗ; TASK-063, TASK-115).

### REQ-GRP-003. Недельный график группы

**Статус:** реализовано

График задаётся набором записей «день недели + время начала»
(минимум один день, без дублей) с общей длительностью занятия
1–180 минут. Время начала задаётся на каждый день недели отдельно.
Свободный текст расписания не используется. Расписание отображается как
локальное время без пересчёта часовых поясов.

**Изменения:**

- 27.08.2026 — новая (источник: TASK-034, TASK-117; заменяет правило
  MVP-ТЗ «время начала + график тренировок»).

### REQ-GRP-004. Календарь занятий

**Статус:** реализовано

Расписание — полноценный календарь конкретных занятий: серия занятий
(`LessonSeries`: дата старта, необязательная дата окончания, бессрочные
серии) с лениво материализуемыми занятиями (`LessonOccurrence`) со
стабильными идентификаторами. Поддерживаются несколько занятий группы в
один день, разовые занятия, перенос и изменение с тремя scope («только это»,
«это и будущие», «вся серия»), отмена и восстановление. Жизненный цикл
занятия: `Scheduled | Cancelled`. Отмена занятия с существующими отметками
посещений блокируется конфликтом. Точные пересечения занятий одной группы —
ошибка валидации; пересечения разных групп — неблокирующее предупреждение.

**Изменения:**

- 27.08.2026 — новая (источник: TASK-119; развивает REQ-GRP-003).

### REQ-GRP-005. Экран расписания

**Статус:** реализовано

Read-only раздел «Расписание» для всех сотрудников: недельная сетка с
временной осью на desktop/tablet (переключатель «Неделя/День», режим в URL),
список дня на mobile. Фильтры: филиал, зал, тренер, группа, тип группы —
применяются совместно. Расписание тренера ограничено его эффективным охватом
(назначения + активные замещения).

**Изменения:**

- 27.08.2026 — новая (источник: TASK-035, TASK-043, TASK-087, TASK-112,
  TASK-113).

### REQ-GRP-006. Замещение тренера

**Статус:** реализовано

Периодное замещение тренера в группе (диапазон дат, границы включительные).
Создание/отмена — роли с правом управления тренерами группы. На активный
период замещающий получает тот же backend-охват группы: клиенты,
расписание, посещаемость; вне периода доступ снимается автоматически.
Основной тренер не затрагивается. Всё аудируется.

**Изменения:**

- 27.08.2026 — новая (источник: TASK-073).
