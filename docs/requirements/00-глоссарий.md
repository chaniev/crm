# Глоссарий

Термины продукта, используемые в карточках требований. Пополнение — в той же
задаче, которая вводит новый термин.

- **Филиал** — отдельная площадка клуба; клиент, группа и каталог абонементов
  привязаны строго к одному филиалу.
- **Зал** — помещение внутри филиала, в котором проходят занятия группы.
- **Клиент** — посетитель зала, учетная карточка в системе.
- **Контактное лицо** — связанное с клиентом лицо (мама, папа или
  произвольный тип) с телефоном.
- **Группа** — тренировочная группа клиентов; относится к одному филиалу и
  залу, имеет тип и недельный график занятий.
- **Тип группы** — справочник в настройках (название, описание).
- **Серия занятий (LessonSeries)** — график группы: дни недели с временем
  начала, дата старта и необязательная дата окончания.
- **Занятие (LessonOccurrence)** — конкретная тренировка серии в конкретную
  дату с уникальным идентификатором; к ней привязывается посещение.
- **Замещение тренера** — периодное назначение тренера в группу на dates
  диапазон с полным доступом к группе на этот период.
- **Абонемент** — право клиента посещать занятия; виды: разовый (`SingleVisit`),
  на срок (`Term`), профессиональный (`Professional`).
- **Каталог абонементов** — справочник вариантов абонементов филиала.
- **Продажа (ClientMembershipSale)** — состоявшееся приобретение абонемента
  с датой покупки и фактически уплаченной суммой.
- **Возврат (ClientMembershipRefund)** — частичный или полный возврат суммы
  продажи; допускается несколько возвратов в пределах суммы продажи.
- **Целевые группы абонемента** — упорядоченный набор групп, на которые
  действует абонемент (1–5 для Term/Professional, ровно 1 для SingleVisit).
- **Entitlement** — разрешение на посещение, которое backend выбирает при
  отметке посещения при пересекающихся абонементах.
- **Посещение** — отметка `Был` / `Не был` / `Не отмечено` по клиенту и
  занятию.
- **Сотрудник** — учетная запись в системе: тренер, администратор,
  супер-администратор или главный тренер.
- **Роль** — HeadCoach (Главный тренер), SuperAdministrator
  (Супер-администратор), Administrator (Администратор), Coach (Тренер).
- **«Клиенты, требующие внимания»** — backend-состояния: истекающий (≤3 дней)
  или истёкший абонемент, серия из 3+ пропусков.
- **Бот сотрудников** — Telegram-бот для быстрых операционных действий
  сотрудников CRM.
- **Чат с клиентами** — двусторонний текстовый чат с клиентами через
  отдельный официальный Telegram-бот клуба.
- **Аудит** — append-only журнал действий сотрудников.
