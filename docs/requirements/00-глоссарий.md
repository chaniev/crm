# Глоссарий

Термины продукта, используемые в карточках требований. Пополнение — в той же
задаче, которая вводит новый термин.

- **Клиент** — посетитель зала, учетная карточка в системе.
- **Контактное лицо** — связанное с клиентом лицо (мама, папа или
  произвольный тип) с телефоном.
- **Группа** — тренировочная группа клиентов с расписанием.
- **Абонемент** — купленный клиентом тариф с датой покупки и сроком действия.
- **Посещение** — отметка о том, что клиент был на тренировке.
- **Пользователь** — учетная запись сотрудника (тренера, администратора,
  главного тренера) для входа в систему.
- **Роль** — Главный тренер, Администратор, Тренер; определяет доступ.
- **Аудит** — журнал действий пользователей в системе.
- **Бот** — клиент системы в мессенджере, потребляющий внутренний Bot API.
