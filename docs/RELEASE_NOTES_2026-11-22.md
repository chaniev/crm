# Обновление CRM от 22 ноября 2026 года

## Клиенты и абонементы

- Клиента можно найти по нескольким словам из ФИО. Это помогает различать однофамильцев.
- В карточке клиента пять вкладок — «Основная информация», «Абонементы», «Посещения», «Группы» и «Сообщения». Контакты и состав групп сохраняются отдельно. В профиль можно записать имя пользователя в Telegram.
- Если в карточке есть фотография, сотрудник с доступом к клиенту может открыть её в личном чате с ботом.
- При продлении новый абонемент начинается на следующий день после окончания того абонемента, который вы выбрали.

## Расписание и посещения

- Для группы можно назначить замещающего тренера на период. CRM и бот учитывают даты замещения. По окончании или после отмены периода доступ по этому назначению прекращается.
- При переходе из расписания в посещения сохраняется выбранное занятие. Если часть группы уже отмечена, можно показать весь состав и вернуться к списку неотмеченных. Дата, занятие и поставленные отметки сохраняются при переключении.
- История посещений и подсчёт пропусков учитывают время конкретного занятия, в том числе когда в один день проходит несколько тренировок.
- Если зал используется в расписании, CRM объяснит причину, по которой его нельзя архивировать или удалить.

## Ежедневная работа

- В разделе «Требуют внимания» каждый клиент показан один раз со всеми причинами. На телефоне из списка можно сразу позвонить.
- В расписании рядом с днём недели видна дата. При настройке группы выбирать дни недели на сенсорном экране стало проще.
