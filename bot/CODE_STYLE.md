# Кодстайл Python для Telegram-бота

## Форматирование и импорты

- Используйте Ruff для форматирования. Отступ — 4 пробела, целевая длина строки — 100 символов. Для строк форматтер предпочитает двойные кавычки.
- Группируйте импорты в порядке «стандартная библиотека, сторонние пакеты, модули бота», с пустой строкой между группами. Сортировку проверяет правило Ruff `I`. Также включены группы `E`, `F`, `B` и `UP` для Python 3.13. [Конфигурация Ruff](pyproject.toml#L42)

## Имена и типы

- Называйте модули, функции и переменные в `snake_case`, классы в `PascalCase`. [Пример клиента CRM](src/gym_crm_bot/crm/client.py)
- Указывайте типы параметров и возвращаемых значений функций. Для `async def` аннотируйте результат, который получит вызывающий код после `await`. Для пакета `src/gym_crm_bot` включён строгий режим mypy. [Конфигурация mypy](pyproject.toml#L55)

При проверке бота репозиторий запускает линтер и форматтер Ruff в режиме проверки и проверяет типы пакета через mypy. [Порядок проверки](../docs/HARNESS.md)
